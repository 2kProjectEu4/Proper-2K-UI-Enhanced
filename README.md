# Proper 2K UI Enhanced

**Ironman compatible and eligible for achievements.**

![Proper 2K UI Enhanced preview](https://i.imgur.com/Uf8Z21n.png)

## Overview

**Proper 2K UI Enhanced** builds upon the original [Proper 2K UI Project](https://steamcommunity.com/sharedfiles/filedetails/?id=2863086388) to better align with the original Europa Universalis IV interface design. The project has been cleaned up, and removed assets have been organized into submods for flexibility.

Contributions from **Xyarvius** and the author include:

- Adjusted text and UI element positioning for a more visually appealing layout and less overlap.
- Enlarged several windows to better fit larger fonts.
- Fixed most progress bar glitches.
- Fixed tutorials.
- Enhanced important UI windows, including the Holy Roman Empire and Emperor of China windows.

See the [changelog](https://1drv.ms/w/c/7b95816d69498287/EWJO_WJBv4hMvEyQ4CBhL8wBQ7eopdgw_ipZZkrFRs4-Dw?e=IFWDwT) for a detailed list of changes.

This is a standalone mod. You do not need to download the original version.

## 4K Version

### Short answer

No, a dedicated 4K version is not planned.

### Why

The improvements in this mod were made manually by playing the game, noting issues, and fixing them in free time. Scaling the current version to 4K would still require substantial manual work.

As an alternative, try using the game's GUI scaling feature with a value between **1.2** and **1.3**. This is not a perfect solution, but it may improve the experience on larger displays.

## 1920x1080 Displays

The mod does not support 1920x1080 by default. NVIDIA users can use DSR to run the game at 2560x1440:

1. Open **NVIDIA Control Panel**.
2. Expand **Manage 3D Settings** and select **Manage 3D Settings**.
3. In the **Global Settings** tab, find **DSR - Factors**.
4. Enable **1.78x (2560x1440)**. If needed, set **DSR - Smoothness** to **33%**.
5. Right-click the desktop and open **Display settings**.
6. Set the display resolution to **2560 x 1440 (2K)**.

Thanks to 柏木由紀 for suggesting this approach in the comments.

## Compatibility Notes

This mod works best at **2560x1440 (QHD)** for optimal performance and visual quality. Activate all DLCs when possible, since some bugs may occur without them.

Most mods are incompatible with Proper 2K UI Enhanced. Before reporting an issue, deactivate mods that are not listed in the [P2KE Submods and Patches collection](https://steamcommunity.com/sharedfiles/filedetails/?id=3325833509) and check whether the issue remains.
